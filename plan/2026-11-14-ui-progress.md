# UI: прогресс

Запрос пользователя: убрать мерцание, исправить cd, добавить различимые emoji
типов команд; узкое меню у курсора с акцентной рамкой, раскрытием вверх/вниз.

## Найденные причины

- Меню принудительно стиралось в line-pre-redraw до получения замены.
  Кроме этого, первый пустой ответ из кэша трактовался как окончательный.
- После таймаута completion воркер оставался выключенным до нового промпта.
  Воспроизведено: slowui → таймаут → Ctrl+U → cd, без Enter — пустое меню.
  Обычный cd сам по себе возвращает каталоги через живой compsys.
- Типы alias/function/builtin не различались в модели кандидатов.

## Изменения

- При редактировании сохраняется предыдущий видимый кадр. Он помечается
  устаревшим и не может вставить старый BUFFER. Ghost снимается, смещения
  подсветки корректируются. WAIT отличает ожидание от окончательного CLEAR.
- Новый ввод после таймаута/падения воркера инициирует его асинхронное
  пересоздание, не требуя Enter и нового промпта.
- Типы определяются из tags compsys и живых aliases/functions/builtins/commands.
  Добавлены emoji и текстовые обозначения binary/alias/function/builtin и др.
- Ширина определяется содержимым и ограничена menu.max_width (48 по умолчанию).
  Рамка по умолчанию акцентная, fg=4; пользовательский theme.border сохраняется.

## Архитектурный выбор (принят)

Пользователь выбрал PTY-обёртку `ziro shell`. Реализована и проверена
tests/overlay_smoke.py: размещение под/над курсором, resize, alt screen,
Tab/Enter/Escape, Ctrl+C/Ctrl+Z, код выхода, SIGTERM/SIGKILL с восстановлением
termios. Source-режим (POSTDISPLAY) сохранён.

## Найдено и исправлено при доводке (14.11)

- Обёртка не завершалась после exit: Command держал копии slave-PTY.
- Воркер наследовал zle -F обработчики (async-промпт oh-my-zsh) и читал их
  пайпы — промпт превращался в мусор. Воркер теперь снимает их и закрывает fd.
- Демон дважды запускал compsys на один ввод (idle refresh того же буфера).
- Дубли `echo` (builtin + /usr/bin/echo); точное совпадение ранжируется первым.
- Emoji с VS16 (⚙️ ↪️) заменены на однозначно широкие (📦 🔹).

## Проверки

- tests/ui_smoke.py: cd с пустым аргументом, медленный набор, пробелы,
  относительные/абсолютные пути, ~/ и вложенные каталоги; восстановление после
  таймаута без Enter; реальные типы команд и emoji.
- tests/frame_state.zsh: сохранение кадра, снятие ghost, смещения подсветки,
  запрет принятия устаревшего кандидата.
- cargo test / clippy: модели типов, ширины emoji, компактность и протокол WAIT.

Проверки с PTY и Unix-сокетами требуют выхода из сетевой sandbox. Используются
только временные rc-файлы/сокеты/базы, пользовательские настройки не меняются.
