# План: стабильное меню, пути и различимые типы подсказок

Запрос: убрать мерцание, восстановить пути для cd, сделать узкое меню у
курсора с акцентной рамкой и понятными emoji типов. Оптимизацию Git не трогаем.

## Решение

- Не обнулять POSTDISPLAY перед каждым ответом. На изменении строки немедленно
  инвалидировать возможность вставки старых кандидатов, сохранив видимый кадр
  до актуального ответа. Очистка — только при закрытии/недопустимом контексте
  или окончательном пустом результате. Сдвиг подсветки вслед за BUFFER.
- Проверить cd в реальном ZLE: пустой аргумент, относительный/абсолютный путь,
  ~/ и вложенный каталог, одиночный каталог, пробелы. Исправить найденную причину;
  штатный compsys сохраняет CDPATH и пользовательские определения.
- Различать alias/function/builtin/binary/dir/file/option/history по данным
  живого zsh; emoji с корректной шириной и символьными смещениями.
- Компактная ширина по содержимому, акцентная рамка. Уточнение пользователя:
  якорь у курсора, движение вправо, раскрытие выше/ниже по свободному месту.
  POSTDISPLAY может рисовать только после ввода. Решение о PTY-обёртке
  `ziro shell` ожидает ответа пользователя; не подменять это приближением.

## Выполнение

1. Воспроизвести cd и мерцание в изолированном PTY; добавить регрессии.
2. Исправить жизненный цикл кадров и cd, проверить отсутствие вставки старого кадра.
3. Добавить категории и emoji, проверить реальные alias/function/builtin и ширины.
4. После ответа пользователя реализовать подход к позиционированию и терминальному рендеру.
5. cargo fmt/clippy/test, реальные zsh/oh-my-zsh/tmux, release-сборка.

Ограничения: никакой записи в ~/.zshrc и установки в систему. Никакого ожидания
воркера/диска/процесса в обработке клавиш. Тесты — по исходному плану, без
обязательного test-first; обязательны проверки сложной логики.
