# Выполнение плана ziro

Ветка: `feat/ziro-mvp`. Исходный дизайн и план сохранены без изменений.

| Задача | Состояние |
|---|---|
| 0. Постоянный zpty | Работает; пять контекстов и 2000 запросов в одном процессе |
| 1. Workspace/протокол | Реализованы, включая фрейминг, направления сообщений и валидацию |
| 2. История | SQLite/WAL, импорт, frecency и статистика аргументов реализованы |
| 3. Конфиг/кандидаты | Реализованы; реальные фикстуры compsys |
| 4. Rank/ghost | Реализованы; p95 ранжирования пока выше бюджета 1 мс |
| 5. Layout/apply | Реализованы; Unicode, ширины, кавычки и LF проверены |
| 6. Демон | Работает; IPC, кэш, поколения, coalescing и таймауты проверены |
| 7. Плагин | Работает; смена cwd из виджета, зависший воркер и SIGKILL демона проверены |
| 8. Клавиши | Проверены menu/explicit, vi Esc и повторная история |
| 9. Ghost/CLI/совместимость | Реализованы; полное поведение конфигурации биндингов при reload отложено |
| 10. Приёмка | Частично: автоматические PTY/tmux/oh-my-zsh; ручная kitty/10 минут TRACE и все бюджеты ещё не закрыты |

Коммиты используют отдельную авторскую идентичность `Codex <codex@localhost>`:
в исходной среде git user.name/user.email не заданы, настройки пользователя
не менялись. Задачи собраны в цельный рабочий коммит, затем отдельный коммит
исправлений ревью. Разработка велась в новом репозитории на feature-ветке;
предшествующего кода или ветки main не было.

План явно требует тесты без test-first; это правило соблюдено. Четыре важных
замечания независимого ревью исправлены и покрыты регрессионными проверками.
Мелкое отложенное замечание: после изменения клавиш в конфиге нужна новая
оболочка. Ручная приёмка и невыполненные бюджеты перечислены в
[spikes/RESULTS.md](../spikes/RESULTS.md).

Функциональные тесты и benchmark — разные проверки: зелёный `cargo test`
не означает выполнения бюджета `rank_bench`.
